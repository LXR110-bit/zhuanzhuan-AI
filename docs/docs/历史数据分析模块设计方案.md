# 云电脑价格扫描 - 历史数据分析模块设计方案

## 一、现状分析

### 现有能力
| 模块 | 位置 | 功能 |
|------|------|------|
| `price_archiver.py` | `./运动相机追踪/scripts/` | 归档每日快照、清理过期数据、生成趋势报告 |
| `analyze.py` | `./运动相机追踪/cloud-pc-monitor/scripts/` | 5种算法投票异常检测、线性回归趋势计算 |

### 现有数据流
```
价格扫描 → price_cache.json → 归档 → trend_history/{产品ID}/{日期}.json
                                    ↓
                              get_price_history() → 趋势报告
```

### 现有问题
1. **历史对比缺失**：只显示当天价格，无法对比7天/30天前
2. **异动检测单一**：只看单点异常，缺少趋势异常判断
3. **日程未调用**：云电脑扫描日程(5:30)没有调用历史分析能力

## 三、异动检测增强逻辑

### 3.1 双重判断机制

```
┌─────────────────────────────────────────────────────────┐
│                    异动检测引擎                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────────────┐    ┌──────────────────┐          │
│  │   单点异常检测    │ AND │   趋势异常检测   │          │
│  │   (Point Anomaly)│    │  (Contextual)    │          │
│  ├──────────────────┤    ├──────────────────┤          │
│  │ • Z-score > 2    │    │ • 偏离度 > 15%   │          │
│  │ • IQR 超出       │    │ • 连续3天同向    │          │
│  │ • 百分位法 5-95  │    │ • 斜率突变       │          │
│  │ • 移动平均偏离   │    │ • 加速信号       │          │
│  └──────────────────┘    └──────────────────┘          │
│           ↓                       ↓                    │
│           └───────────┬───────────┘                    │
│                       ↓                                 │
│              ┌────────────────┐                         │
│              │  异动判定      │                         │
│              ├────────────────┤                         │
│              │ 需要同时满足   │                         │
│              │ 至少1种单点   │                         │
│              │ + 至少1种趋势 │                         │
│              └────────────────┘                         │
└─────────────────────────────────────────────────────────┘
```

### 3.2 异动分级

| 级别 | 单点异常 | 趋势异常 | 描述 | 推送策略 |
|------|----------|----------|------|----------|
| 🔴 S级 | ✅ ≥2种 | ✅ ≥1种 | 强烈异动，需立即关注 | 立即推送 |
| 🟠 A级 | ✅ ≥1种 | ✅ ≥2种 | 趋势异动，可能持续 | 24h内推送 |
| 🟡 B级 | ✅ ≥1种 | ❌ | 偶发异常，待观察 | 加入监控 |
| 🟢 C级 | ❌ | ✅ ≥1种 | 趋势变化，关注但不急 | 日报汇总 |

### 3.3 代码实现

```python
def detect_enhanced_anomaly(product_id: str) -> Dict:
    """增强版异动检测"""
    results = {
        "point_anomaly": {
            "detected": False,
            "methods": [],
            "severity": 0
        },
        "trend_anomaly": {
            "detected": False,
            "methods": [],
            "severity": 0
        },
        "final_level": None,
        "action_required": None
    }
    
    # 单点异常检测
    point_methods = [
        ("zscore", detect_zscore_anomaly),
        ("iqr", detect_iqr_anomaly),
        ("percentile", detect_percentile_anomaly),
        ("moving_avg", detect_moving_avg_anomaly)
    ]
    
    for method_name, method_func in point_methods:
        if method_func(product_id):
            results["point_anomaly"]["detected"] = True
            results["point_anomaly"]["methods"].append(method_name)
            results["point_anomaly"]["severity"] += 1
    
    # 趋势异常检测
    trend_methods = [
        ("deviation", check_deviation_anomaly),      # 偏离度异常
        ("consecutive", check_consecutive_anomaly),  # 连续同向
        ("slope_change", check_slope_anomaly),       # 斜率突变
        ("acceleration", check_acceleration_anomaly) # 加速信号
    ]
    
    for method_name, method_func in trend_methods:
        if method_func(product_id):
            results["trend_anomaly"]["detected"] = True
            results["trend_anomaly"]["methods"].append(method_name)
            results["trend_anomaly"]["severity"] += 1
    
    # 判定最终级别
    if results["point_anomaly"]["severity"] >= 2 and results["trend_anomaly"]["severity"] >= 1:
        results["final_level"] = "S"
    elif results["point_anomaly"]["severity"] >= 1 and results["trend_anomaly"]["severity"] >= 2:
        results["final_level"] = "A"
    elif results["point_anomaly"]["severity"] >= 1:
        results["final_level"] = "B"
    elif results["trend_anomaly"]["severity"] >= 1:
        results["final_level"] = "C"
    
    return results
```
