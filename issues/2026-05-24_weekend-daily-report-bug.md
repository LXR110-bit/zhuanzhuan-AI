# Bug: 日报周末误推送 + 每日双推

## 发现时间
2026-05-24 00:54（用户反馈）

## 问题描述

日报系统存在两个配置错误：

### 1. 周末也在推日报

用户明确要求：**只周内（周一到周五）发日报，周末不发**。

但当前所有日报相关日程的 rrule 都是 `DAILY`，导致周六日也在执行和推送。

**受影响日程：**
| 日程 | uid前缀 | 当前rrule | 应改为 |
|------|---------|-----------|--------|
| 闲鱼采价+日报生成 | 7a38b338 | DAILY | WEEKLY MO-FR |
| 日报推送（只推不生成）| ba29b2a2 | DAILY | WEEKLY MO-FR |
| 晚间全量异动检测 | d7bfc48f | DAILY | 应删除（不需要晚间日报）|
| 异动检测-午间 | 03b0f935 | DAILY | WEEKLY MO-FR（待确认）|
| 异动检测-晚盘 | ff7de555 | DAILY | WEEKLY MO-FR（待确认）|

### 2. 一天推两次日报（早+晚）

用户要求：**只早上发图片日报+文案链接**。

但当前配置：
- 06:30 闲鱼采价+日报生成 → 10:00 日报推送（早上）
- 21:30 晚间全量异动检测 → 又生成+推送一次（晚间）

晚间日报日程是5/22新增的（uid: d7bfc48f），创建时没有考虑用户的实际需求。

## 历史推送记录（从 runtime log 提取）

### 2026-05-22（周四）
- 16:29 日报卡片生成（成功，由周报触发）
- 21:52 晚间日报生成（成功，S级1个）
- 21:53 企微推送失败："daily report already sent; push deadline passed: after 11:00"

### 2026-05-23（周六）← 不该推的日子
- 06:42 日报卡片生成（成功）
- 10:28 日报推送企微+扣子（成功）← 周六不该推
- 21:53 晚间日报再次生成+推送尝试（被 guard 拦截）

## 根因

1. 日程创建时 rrule 一律用 `DAILY`，没有区分工作日和周末
2. 5/22 新增晚间日报日程时，没有和用户确认是否需要晚间推送
3. 用户原始需求是"只周内早上发"，但配置脱离了需求

## 修复方案

### 必须改
- [ ] 闲鱼采价+日报生成：DAILY → WEEKLY MO-FR
- [ ] 日报推送（只推不生成）：DAILY → WEEKLY MO-FR
- [ ] 删除晚间全量异动检测日程（不需要晚间日报）

### 待确认
- [ ] 异动检测-午间：是否也只周内？
- [ ] 异动检测-晚盘：是否也只周内？还是直接删？
- [ ] TikHub资讯采集、微博监控等采集类日程：周末数据采集是否继续？（采集可以跑，但推送只周内）

## 附：日程 rrule 配置参考

正确的周内日程 rrule：
```json
{"freq": "WEEKLY", "interval": 1, "byday": ["MO", "TU", "WE", "TH", "FR"]}
```
