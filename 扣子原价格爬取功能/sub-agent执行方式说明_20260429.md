# sub-agent执行方式说明

**版本**: v1.0  
**日期**: 2026-04-29  
**核心结论**: 价格爬取必须通过Calendar→sub-agent→工具调用，Python脚本无法替代

---

## 一、执行架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      日程调度层（Calendar）                               │
│                                                                          │
│  calendar_create 创建日程，description中写入完整任务描述                  │
│  到达时间后，系统自动创建sub-agent session执行                            │
│                                                                          │
│  触发时间：                                                               │
│  - 市场追踪日报：06:00                                                    │
│  - 白天异动检测：07:30 / 12:00 / 17:30                                   │
│  - 晚间全量检测：21:00                                                    │
│  - 云电脑扫描：每2小时                                                    │
└───────────────────────────┬─────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    sub-agent session（独立执行）                          │
│                                                                          │
│  特性：                                                                   │
│  1. 拥有汤米的全部工具权限（search_web、mobile_use、bash等）               │
│  2. 共享汤米的文件系统（可读写 ./运动相机追踪/ 目录）                       │
│  3. 共享汤米的记忆文件（可读取 ./MEMORY.md、./USER.md 等）                 │
│  4. 异步执行，完成后自动返回结果                                          │
│                                                                          │
│  核心能力：                                                               │
│  - search_web：联网搜索价格信息（云电脑）                                 │
│  - mobile_use：操作云手机App（云手机）                                    │
│  - bash：执行Python脚本（可选）                                          │
│  - read_file/write_file：读写文件                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 二、为什么Python脚本无法替代sub-agent

| 功能 | Python脚本 | sub-agent | 结果 |
|------|-----------|-----------|------|
| **search_web工具** | ❌ 无法调用（这是汤米的工具） | ✅ 可以调用 | 脚本失败 |
| **mobile_use工具** | ❌ 无法调用（这是云手机操作） | ✅ 可以调用 | 脚本失败 |
| **requests爬网页** | ⚠️ 可以，但会被反爬拦截 | 不需要 | blocked |
| **文件读写** | ✅ 可以 | ✅ 可以 | 两者都可 |

**结论**：
- 配置文件（categories.json、thresholds.json）可以用Python脚本处理
- 数据爬取（search_web、mobile_use）必须通过sub-agent

## 三、关键文件清单

| 文件 | 作用 | 必须保留 |
|------|------|----------|
| `config/categories.json` | 统一品类配置 | ✅ |
| `config/thresholds.json` | 统一阈值配置 | ✅ |
| `config/schedule.json` | 统一时间配置 | ✅ |
| `scripts/price_data_validator.py` | 价格验证 | ✅ |
| `scripts/price_archiver.py` | 价格归档 | ✅ |
| `scripts/price_crawler.py` | 爬取脚本 | ❌ 无法工作 |
| `scripts/run_daytime_scan.py` | 执行入口 | ❌ 无法工作 |
