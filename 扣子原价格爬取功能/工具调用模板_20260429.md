**版本**: v1.0  
**日期**: 2026-04-29  
**用途**: sub-agent在执行价格爬取时，调用工具的标准模板

---

## 一、工具能力对比

| 工具 | 执行位置 | 能力 | 配额消耗 |
|------|----------|------|----------|
| **search_web** | 云电脑 | 联网搜索，获取网页信息 | 无限制 |
| **mobile_use** | 云手机 | 操作手机App，爬取实时数据 | 每日限制 |
| **bash** | 云电脑 | 执行Python脚本 | 无限制 |

## 二、search_web调用模板

### 2.1 基础价格搜索

**用途**：获取闲鱼市场价、电商价格

```
搜索 "{机型名} 价格"，从搜索结果中提取：
1. 价格区间（最低价、最高价、平均价）
2. 数据来源（官网、电商、二手平台）
3. 样本数量

注意：
- 不要搜索"成交"等敏感关键词
- 优先采信官网、大型电商的价格
- 二手平台价格需标注来源
```

### 2.2 资讯搜索

**用途**：获取新品发布、降价等资讯

```
搜索 "{关键词}"，提取最新资讯：
1. 发布时间
2. 事件类型（新品发布/官方降价/活动促销）
3. 具体内容摘要
4. 信息来源

关键词示例：
- 大疆 新品 发布 2026
- RTX 4070 降价
- DDR5 内存 价格 2026
```

### 2.3 价格搜索示例

```
# 示例1：显卡价格
搜索 "微星 RTX 3070 价格"
期望结果：
- 闲鱼二手价：¥1800-2500
- 京东全新价：¥3500-4200
- 数据来源：闲鱼、京东、淘宝

# 示例2：运动相机价格
搜索 "DJI Pocket 3 价格"
期望结果：
- 闲鱼二手价：¥1800-2300
- 官方停售
- 数据来源：闲鱼、大疆官网
```

## 三、mobile_use调用模板

### 3.1 闲鱼市场价爬取

**用途**：获取闲鱼二手市场价（用户卖给用户）

```
在闲鱼App搜索"{search_term}"，筛选"轻微使用痕迹"，
向下滚动收集至少15条商品价格，返回所有价格列表。
禁止搜索"成交"关键词。超时90秒。
```

**search_term示例**：
- "微星 RTX 3070"
- "DJI Pocket 3"
- "i5 13600K"

**期望返回**：
```json
{
  "prices": [1850, 1900, 1920, 1950, ...],
  "count": 15,
  "min": 1850,
  "max": 2200,
  "avg": 1980,
  "condition": "轻微使用痕迹（9成新）"
}
```

### 3.2 闲鱼官方回收价爬取

**用途**：获取闲鱼官方回收价格（平台回收，高价省心）

```
在闲鱼App搜索"{search_term}"，进入回收服务页面，
获取官方回收价格。筛选"轻微使用痕迹"（对应9成新），
返回价格数据。超时90秒。
```

**注意**：
- 仅支持手机/数码/手环品类
- PC硬件（显卡/CPU/内存）可能返回"暂无报价"

**期望返回**：
```json
{
  "official_recycle_price": 1344,
  "condition": "9成新",
  "next_week_estimate": 1280,
  "note": "闲鱼官方回收价"
}
```

### 3.3 爱回收价爬取

**用途**：获取爱回收平台价格（竞品定价参考）

```
打开爱回收App，搜索"{search_term}"，
获取基础价、券后价、碳索家价。超时90秒。
```

**期望返回**：
```json
{
  "base_price": 1400,
  "after_coupon": 1650,
  "tansuo_price": 1692,
  "condition": "9成新",
  "note": "爱回收官方估价"
}
```

### 3.4 mobile_use执行注意事项

**配额管理**：
- 每日总配额：有限（具体数量待确认）
- 白天异动检测：仅在发现异动时触发
- 晚间全量检测：固定消耗1次/晚

**超时设置**：
- 单机型硬超时：90秒
- 重试次数：最多2次
- 重试间隔：10秒

**执行策略**：
- 纯串行执行（一次只爬一个机型）
- 机型间隔：5秒
- 硬截止时间：23:00

## 五、混合执行流程

### 5.1 白天异动检测流程

```
sub-agent 执行：
  │
  ├── Step 1: 读取配置文件（read_file）
  │
  ├── Step 2: search_web 搜索价格（云电脑）
  │     ├── "微星 RTX 3070 价格"
  │     ├── "i5 13600K 价格"
  │     └── ...
  │
  ├── Step 3: 异动判断（内部逻辑）
  │     └── 变动 ≥ 10%？
  │
  ├── Step 4: [如有异动] mobile_use 验证（云手机）
  │     ├── 打开闲鱼App → 爬取价格
  │     └── 或 打开爱回收App → 爬取价格
  │
  ├── Step 5: 写入缓存（write_file）
  │     └── data/price_cache.json
  │
  └── Step 6: 生成日报
```

### 5.2 晚间全量检测流程

```
sub-agent 执行：
  │
  ├── Step 1: 读取配置文件（read_file）
  │
  ├── Step 2: mobile_use 爬取所有机型（云手机）
  │     ├── 机型1: 闲鱼 + 爱回收
  │     ├── 机型2: 闲鱼 + 爱回收
  │     └── ...（纯串行，每机型90秒）
  │
  ├── Step 3: 写入缓存（write_file）
  │     └── data/price_cache.json
  │
  ├── Step 4: bash 执行Python脚本（云电脑）
  │     ├── price_data_validator.py（验证）
  │     └── price_archiver.py（归档）
  │
  └── Step 5: 生成图片卡片日报
```

## 六、新旧策略执行方式对比

| 维度 | 旧策略（正确） | 新策略（错误） |
|------|---------------|---------------|
| **数据爬取** | sub-agent → search_web/mobile_use | Python脚本 → requests（被block） |
| **配置读取** | sub-agent → read_file | Python脚本 → open()（可以） |
| **价格验证** | 无 | Python脚本（可以） |
| **归档** | Python脚本 | Python脚本（可以） |

**结论**：
- 爬取必须用sub-agent工具
- 配置/验证/归档可以用Python脚本
- 正确做法：sub-agent在爬取完成后调用Python脚本
