# Opus审查报告：行情价格追踪系统改进建议

## P0 — 必须立即解决

### 1. 爱回收全线报0：数据源完全失效

根因：云手机物理位置在呼和浩特，爱回收按地理位置限制服务区域。

- 方案A（推荐）：将爱回收采集任务迁移到一线城市节点的云手机（深圳/北京/上海），成本增量约30-50元/月
- 方案B：改用爱回收H5/小程序的估价接口，通过定位模拟或直接传入城市参数绕过地理限制
- 方案C（兜底）：如果爱回收对非标品类本身就不支持报价，确认后直接下线该数据源

验证标准：连续3天爱回收报价非0，且与闲鱼官方回收价偏差在±15%

### 2. 闲鱼行情价系统性低于官方回收价：数据可信度问题

根因分析：闲鱼"行情价"是C2C成交参考价，"官方回收价"是平台保底收购价。行情价低于回收价逻辑上反常——可能取到了错误字段，或样本不足导致偏低。

实施步骤：
1. 人工复核：选3个机型，手动走一遍闲鱼行情tab完整流程，截图确认采集脚本取的是哪个字段
2. 引入交叉验证：行情价 < 官方回收价*0.85 → 标记data_anomaly；连续7天low_confidence → 降级为仅参考
3. 补充数据源锚定：爬取闲鱼同机型近7天实际成交帖（已售标记），取中位数作为市场价基准

### 3. 上游供应链信号缺失

需补充的关键词：

微博（产业新闻最快）：NAND Flash涨价、DRAM现货价、存储芯片缺货、台积电产能、英伟达供货、大疆新品发布、以旧换新政策、国补

B站（深度分析）：存储涨价预警、显卡矿潮、大疆禁令、DDR5涨价、SSD价格走势

抖音（市场情绪）：存储涨价囤货、显卡涨价预警、大疆被禁、以旧换新补贴、国补电子产品

小红书（消费者换机决策）：大疆以旧换新、GoPro13换机、影石X5换X4、运动相机怎么选2025

新增免费信号源：DRAMeXchange/TrendForce存储芯片现货价周报（免费RSS）、大疆官网/公众号新品监控、工信部/商务部补贴政策更新

## P1 — 本周内规划

### 4. 从"信号发现"升级到"动作建议"

信号→动作映射规则引擎：

| 信号类型 | 建议动作 | 触发条件 |
|----------|----------|----------|
| 行情价连续3天下跌>5% | 暂停高价回收，降低报价 | 自动告警 |
| 行情价连续3天上涨>5% | 提高报价抢量，短信召回 | 自动告警 |
| 上游涨价信号 | 预判7天后涨价，提前囤货 | 人工确认 |
| 新品发布/评测爆发 | 旧款将贬值，加速出货 | 自动告警 |
| 以旧换新政策发布 | 配合政策做召回活动 | 人工确认 |
| 竞品提价 | 跟价或差异化策略 | 自动告警 |

### 5. TikHub超时与API预算优化

稳定性：加入重试机制（超时30min重试，最多3次）、降级逻辑、超时24h自动告警

86次/月预算优化：
- 高频（每周2次）：华强北行情、以旧换新、存储涨价
- 低频（每2周1次）：评测类、泛品类关键词
- 免费补充：微博热搜API、IT之家RSS、大疆公众号监控

## P2 — 两周内落地

### 6. 数据质量体系化

置信度评分模型 = weighted_average(数据源数量, 多源交叉验证, 数据新鲜度, 历史波动率)
只有置信度>=中的数据才进入决策环节

### 7. 补充竞品价格监控

优先级：转转历史价 > 华强北渠道价 > 拍拍回收价 > 找靓机

## P3 — 月度迭代

### 8. 品类特异性优化

| 品类 | 核心驱动 | 重点监控 |
|------|----------|----------|
| 显卡 | 新品周期、矿潮、AI需求 | 英伟达发布会、以太坊政策 |
| 内存固态 | 上游NAND/DRAM现货价 | TrendForce周报 |
| 运动相机 | 新品发布、季节性 | 大疆/影石发布会 |
| 无人机 | 政策禁飞/出口管制 | 民航局政策 |
| CPU | 新架构发布 | Intel/AMD发布会 |
| 智能手环 | 新品频率高、贬值快 | 华为/小米新品 |

### 9. 召回ROI优化闭环

- 行情上涨期：加大召回（"您的XX现在值XXX元"是强召回话术）
- 行情下跌期：减少召回投放
- 新品发布前1-2周：精准召回旧款用户
- 系统输出"本周建议召回的品类+话术要点"
