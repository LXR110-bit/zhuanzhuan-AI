# 双卡片模板设计

---

## 卡片1：市场追踪日报（早上播报）

### 布局描述
```
┌──────────────────────────────┐
│  顶部渐变条 (深蓝→靛蓝)      │
│  📡 市场追踪日报              │
│  {date} {weekday}            │
├──────────────────────────────┤
│  💬 今日一句话                │
│  ┌────────────────────────┐  │
│  │ {summary}              │  │
│  └────────────────────────┘  │
│  🔴 S级信号                   │
│  ┌────────────────────────┐  │
│  │ • {s_signal_1}         │  │
│  │ • {s_signal_2}         │  │
│  └────────────────────────┘  │
│  🟡 A级信号                   │
│  ┌────────────────────────┐  │
│  │ • {a_signal_1}         │  │
│  │ • {a_signal_2}         │  │
│  └────────────────────────┘  │
│  ✅ 今日建议                  │
│  ┌────────────────────────┐  │
│  │ {suggestion_1}         │  │
│  │ {suggestion_2}         │  │
│  └────────────────────────┘  │
│  底部: logo + 数据来源        │
└──────────────────────────────┘
```

### 生图Prompt
```
A vertical mobile infographic card, 1080x1920px, clean modern dashboard style.

Top header: dark blue to indigo gradient bar with white text "{date} {weekday}" and title "市场追踪日报" with a radar emoji icon.

Below header on light gray (#F5F5F5) background, four stacked content sections:

Section 1 - "今日一句话": a white rounded card with bold large text "{summary}", speech bubble emoji on the left.

Section 2 - "S级信号": a card with 4px red left border, light red background, containing 2 bullet points "{s_signal_1}" and "{s_signal_2}", red circle emoji label.

Section 3 - "A级信号": a card with 4px orange left border, light orange background, containing 2 bullet points "{a_signal_1}" "{a_signal_2}", yellow circle emoji label.

Section 4 - "今日建议": a card with 4px green left border, light green background, containing "{suggestion_1}" and "{suggestion_2}", green checkmark emoji label.

Bottom footer: small gray text with logo and disclaimer.

Style: flat design, SF Pro font style, professional fintech aesthetic, high contrast readable text, Chinese text.
```

## 卡片2：价格监控日报

### 布局描述
```
┌──────────────────────────────┐
│  顶部渐变条 (深青→蓝绿)      │
│  📊 价格监控日报              │
│  {date} 更新于 {update_time} │
├──────────────────────────────┤
│  统计概览 (横向两个指标卡)    │
│  ┌──────────┐ ┌──────────┐  │
│  │ 完成率    │ │ 异动数   │  │
│  │ {rate}%  │ │ {alert_n}│  │
│  └──────────┘ └──────────┘  │
│  📋 价格总览表                │
│  机型 |自由市场|官方回收|爱回收|环比│
│  {model} | {price1} | {price2} | {price3} | {change}│
│  ...                         │
│  🔻 下跌预警                  │
│  {drop_model} ↓{drop_pct}    │
│  🔺 上涨提示                  │
│  {rise_model} ↑{rise_pct}    │
│  底部: 数据来源 | 更新时间    │
└──────────────────────────────┘
```

### 生图Prompt
```
A vertical mobile infographic card, 1080x1920px, clean data dashboard style.

Top header: dark teal to blue-green gradient bar with white text "{date}" and subtitle "更新于 {update_time}", title "价格监控日报" with a bar chart emoji icon.

Below header on light gray background:

Row 1 - Two side-by-side metric cards: left shows "完成率" with large "{rate}%" in teal; right shows "异动数" with large "{alert_n}" in orange.

Row 2 - "价格总览表": a white card containing a data table with columns "机型", "闲鱼自由市场", "闲鱼官方回收", "爱回收", "日环比". Sample rows: "{model_1} | {xianyu_market_1} | {xianyu_recycle_1} | {aihuishou_1} | {daily_change_1}". Daily change shows green for positive and red for negative.

Row 3 - "下跌预警": a card with red left border and light red background, showing "{drop_model}" with down arrow and "{drop_percent}".

Row 4 - "上涨提示": a card with green left border and light green background, showing "{rise_model}" with up arrow and "{rise_percent}".

Bottom footer: small gray text "数据来源: 闲鱼自由市场·闲鱼官方回收·爱回收" and "更新时间: {update_time}".

Style: flat design, data-dense but readable, fintech dashboard aesthetic, Chinese text.
```

---

## 变量清单

| 卡片 | 变量 | 说明 |
|---|---|---|
| 通用 | `{date}`, `{weekday}`, `{update_time}` | 日期时间 |
| 卡片1 | `{summary}` | 一句话核心结论 |
| 卡片1 | `{s_signal_N}`, `{a_signal_N}` | S/A级信号条目 |
| 卡片1 | `{suggestion_N}` | 今日建议条目 |
| 卡片2 | `{rate}`, `{alert_n}` | 完成率、异动数 |
| 卡片2 | `{model_N}`, `{xianyu_market_N}`, `{daily_change_N}` | 表格数据 |
| 卡片2 | `{drop_model}`, `{drop_percent}` | 下跌预警 |
| 卡片2 | `{rise_model}`, `{rise_percent}` | 上涨预警 |
