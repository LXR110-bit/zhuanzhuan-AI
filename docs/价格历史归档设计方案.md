# 价格历史归档系统设计方案

## 一、问题分析

### 现状
- `price_cache.json` 采用覆盖式存储，每次更新会丢失历史数据
- `trend_history/` 目录存在但为空，未被利用
- 无法回看历史价格，无法进行趋势分析

### 目标
- 保留每日价格快照
- 支持查询"某机型过去N天的价格变化"
- 为趋势分析、价格走势图提供数据基础

---

## 二、归档存储结构

### 目录设计
```
运动相机追踪/data/trend_history/
├── DJI_Pocket3/
│   ├── 2026-04-24.json
│   ├── 2026-04-25.json
│   └── 2026-04-26.json
├── DJI_Pocket4/
│   └── 2026-04-26.json
├── RTX_3070/
│   └── 2026-04-26.json
├── RTX_4070/
│   └── 2026-04-26.json
└── i5_13600K/
    └── 2026-04-26.json
```

### 单个归档文件结构
```json
{
  "archived_at": "2026-04-26T18:30:00+08:00",  // 归档时间
  "scan_time": "2026-04-26",                   // 数据日期
  "product_id": "DJI_Pocket3",                // 产品ID
  "data": { ... }                              // 完整价格数据
}
```

## 三、更新流程

### 时机
- **云电脑价格扫描（5:30）** 执行完成后自动归档
- **爱回收价格查询（5:35）** 完成后补充归档

### 流程
```
1. 价格扫描任务完成
2. 调用归档脚本: python price_archiver.py archive
3. 脚本读取 price_cache.json
4. 按产品拆分为独立归档文件
5. 输出归档日志
```

### 归档命令
```bash
cd 运动相机追踪/scripts
python price_archiver.py archive
```

---

## 四、数据清理策略

### 策略
- **保留周期**: 60天
- **清理时机**: 每周一执行清理（由日报生成任务触发）
- **清理方式**: 删除 30 天前的归档文件

### 命令
```bash
python price_archiver.py cleanup
```

**新增**:

## 六、归档脚本功能

### 脚本位置
`./运动相机追踪/scripts/price_archiver.py`

### 功能列表
| 命令 | 功能 |
|------|------|
| `python price_archiver.py archive` | 执行归档 |
| `python price_archiver.py cleanup` | 清理过期数据 |
| `python price_archiver.py report <产品ID> [天数]` | 生成趋势报告 |

### 示例输出
```bash
$ python price_archiver.py report DJI_Pocket3 7

## DJI_Pocket3 价格趋势报告 (近7天)

| 日期 | 回收价(探索加) | 闲鱼均价 | 趋势 |
|------|---------------|----------|------|
| 2026-04-20 | 1850 | 2100 | 稳定 |
| 2026-04-21 | 1820 | 2080 | 小幅下跌 |
| 2026-04-22 | 1800 | 2050 | 小幅下跌 |
| ... | ... | ... | ... |
```

## 八、注意事项

1. **归档时机**: 确保 price_cache.json 已完整更新后再归档
2. **并发安全**: 避免同一时间多次归档同一日期
3. **磁盘空间**: 每月约 5 产品 × 30 天 × 2KB ≈ 300KB，无需特殊处理
4. **数据一致性**: 归档文件名使用 scan_time 字段，而非归档时间
