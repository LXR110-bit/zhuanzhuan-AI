# 扣子防串台提交规范

目标：防止日志、运行数据、反卷教练代码、行情代码在同一次提交里混在一起；允许 Coze 提交轻量运行日志，但禁止提交代码和配置。

## 一、提交前必跑

```bash
python3 scripts/validate_commit_boundary.py
```

## 二、行情仓允许什么

行情仓 `zhuanzhuan-AI` 只允许维护：

- 行情代码：`scripts/`
- 行情配置：`config/`
- 行情文档：`docs/`、`issues/`
- 轻量运行摘要：`ops_logs/`
- Codex 交接单：`handoff/codex/`
- 必要行情缓存：例如 `data/price_cache.json`
- 脱敏排障包：`debug_snapshots/`

## 三、Coze 日志 commit 允许范围

Coze 只允许提交：

```text
ops_logs/runs/YYYY-MM-DD/*.md
ops_logs/schedules/*.md
handoff/codex/*.md
```

commit message 必须以 `ops-log:` 开头。

提交前如果 `git status --short` 出现 `scripts/`、`config/`、`docs/`、模板、版本号或其他代码/配置改动，Coze 必须停止提交并输出交接单。

## 四、行情仓禁止什么

禁止提交：

- 原始日志：`logs/`、`data/logs/`
- 生成卡片/导出文件：`data/report_cards/`、`data/outbox/`、`data/periodic_reports/`
- 真实 webhook key、secret、token
- 反卷教练目录：`skills/anti-involution-coach/`、`skills/anti-pretend-effort/`
- 反卷教练独立仓内容：`zhuanzhuan-anti-coach/`
- 代码/配置变更和运行态 `data/` 文件混在同一个 commit

## 五、需要提交日志怎么办

只提交轻量运行摘要或 Codex 交接单：

```bash
git status --short
git add ops_logs/ handoff/codex/
python3 scripts/validate_commit_boundary.py
git commit -m "ops-log: <task_name> <YYYY-MM-DD>"
git push origin local/dev
```

原始日志和大体积产物不要提交；需要排障时生成脱敏快照。

## 六、推荐提交拆分

- 代码修复：只提交 `scripts/`、`config/`、`docs/`、`issues/`
- 运行摘要：只提交 `ops_logs/`
- 排障交接：只提交 `handoff/codex/` 或 `debug_snapshots/`
