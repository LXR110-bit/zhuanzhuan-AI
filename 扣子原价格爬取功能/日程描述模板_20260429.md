## 一、白天异动检测（07:30/12:00/17:30）

```markdown
## 任务目标
执行A层8个机型轻量价格检测，发现异动后触发mobile_use验证。

---

## 执行流程

### Step 1：读取配置
1. 读取 `./运动相机追踪/config/categories.json` 获取A层机型列表
2. 读取 `./运动相机追踪/data/baseline.json` 获取价格基准线
3. 读取 `./运动相机追踪/data/price_cache.json` 获取上次价格

### Step 2：轻量价格检测（search_web）
对A层每个机型执行search_web：
- 搜索词：机型名（如"微星 RTX 3070"）
- 从搜索结果中提取价格信息
- 记录数据来源、样本量

**search_web调用模板**：
```
搜索 "{机型名} 价格"，从搜索结果中提取：
1. 价格区间（最低价、最高价、平均价）
2. 数据来源（官网、电商、二手平台）
3. 样本数量

注意：
- 不要搜索"成交"等敏感关键词
- 优先采信官网、大型电商的价格
- 二手平台价格需标注来源
```

### Step 3：异动判断
- 价格变动 ≥ 10%
- 或跌破停收阈值

### Step 4：触发深度验证（如有异动）
如果发现异动信号（≥10%变动）：
- 使用mobile_use爬取闲鱼官方回收价验证
- 搜索词严格按照品类配置文件
- 超时90秒

**mobile_use调用模板**：
```
在闲鱼App搜索"{search_term}"，进入回收服务页面，
获取官方回收价格。筛选"轻微使用痕迹"（对应9成新），
返回价格数据。超时90秒。
```

### Step 5：写入价格缓存
将成功抓取的数据写入：`./运动相机追踪/data/price_cache.json`

### Step 6：生成日报
生成日报文件，如有异动推送告警。

---

## 配额管理
- search_web：不消耗配额
- mobile_use：仅在发现异动时触发，每日最多1次

---

## 配置文件
- 品类配置：`./运动相机追踪/config/categories.json`
- 价格缓存：`./运动相机追踪/data/price_cache.json`
```

## 二、晚间全量检测（21:00）

```markdown
## 任务目标
执行A+B层22个机型深度价格爬取，生成图片卡片日报。

---

## 执行流程

### Step 1：读取配置
1. 读取 `./运动相机追踪/config/categories.json` 获取所有机型
2. 读取 `./运动相机追踪/data/price_cache.json` 获取上次价格

### Step 2：三价格口径串行爬取
对每个机型固定抓取三类价格，禁止只抓其中一类后直接生成日报：

**闲鱼市场价调用模板**：
```
在闲鱼App搜索"{search_term}"，筛选"轻微使用痕迹"（对应9成新），
取前5个有效商品价格，返回价格列表和中位数。
禁止搜索"成交"关键词。超时90秒。
```

**闲鱼官方回收价调用模板**：
```
在闲鱼App搜索"{search_term}"，进入回收服务页面，
获取官方回收价格。筛选"轻微使用痕迹"（对应9成新），
返回价格数据。超时90秒。
```

**爱回收价调用模板**：
```
打开爱回收App，搜索"{search_term}"，
获取基础价、券后价、碳索家价。
筛选"轻微使用痕迹"（对应9成新）。超时90秒。
```

**执行策略**：
- 超时：90秒硬上限
- 重试：最多2次，间隔10秒
- 机型间隔：5秒
- 硬截止时间：23:00

### Step 3：写入价格缓存
将成功抓取的数据写入：`./运动相机追踪/data/price_cache.json`

必须写入字段：
- `prices.{product_id}.xianyu_market.price`
- `prices.{product_id}.xianyu_market.samples`
- `prices.{product_id}.xianyu_official.price`
- `prices.{product_id}.aihuishou.base_price`
- `prices.{product_id}.aihuishou.after_coupon`
- `prices.{product_id}.aihuishou.tansuo_price`

如果平台无报价，写入 `null`，并在对应字段写明 `note` / `failure_reason`，禁止推测填充。

### Step 4：执行价格验证（bash）
调用Python脚本验证价格合理性：
```bash
python3 ./运动相机追踪/scripts/price_data_validator.py
```

### Step 5：归档价格历史（bash）
调用Python脚本归档：
```bash
python3 ./运动相机追踪/scripts/price_archiver.py archive
```

### Step 6：生成日报
生成图片卡片日报，推送告警。

---

## 配额管理
- mobile_use：21:00固定触发，使用晚间全量检测预留配额
- 每日总配额以 `config/schedule.json.cloud_phone_quota.daily_limit` 为准
- 晚间全量检测必须保留1次固定额度，不被白天异动验证占用

---

## 配置文件
- 品类配置：`./运动相机追踪/config/categories.json`
- 价格缓存：`./运动相机追踪/data/price_cache.json`
- 执行策略：参考 `./运动相机追踪/白天异动检测/执行策略.json`
```

## 四、云电脑扫描（每2小时）

```markdown
## 任务目标
执行轻量价格扫描，检测异动信号。

---

## 执行流程

### Step 1：读取配置
1. 读取 `./运动相机追踪/config/categories.json` 获取监控机型
2. 读取 `./运动相机追踪/data/baseline.json` 获取基准线

### Step 2：并行search_web检测
对每个机型执行search_web：
- 使用 categories.json 中的 search_keywords
- 从搜索结果中提取价格信息

### Step 3：异动检测
使用5种算法融合检测：
- three_sigma（3σ法则）
- trend_break（趋势突变）
- distribution_shift（分布漂移）
- isolation_forest（孤立森林）
- iqr（四分位距）

≥3个算法同时判定异常 → 确认异动

### Step 4：置信度计算
计算5维度置信度：
- data_source（0.25）
- sample_size（0.20）
- consistency（0.20）
- trend（0.20）
- cross_validation（0.15）

### Step 5：决策输出
- ≥90%：直接记录
- 70-90%：加入告警队列
- <70%：继续观察

### Step 6：归档
调用Python脚本：
```bash
python3 ./运动相机追踪/scripts/price_archiver.py archive
```

---

## 输出文件
- 日志：`./运动相机追踪/data/scan_status.json`
- 归档：`./运动相机追踪/data/trend_history/{产品ID}/{日期}.json`
```
