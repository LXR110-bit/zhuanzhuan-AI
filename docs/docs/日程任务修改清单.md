## 归档数据查询命令

| 用途 | 命令 |
|------|------|
| 查看所有归档 | `ls -la 运动相机追踪/data/trend_history/*/` |
| 查询单产品趋势 | `python3 scripts/price_archiver.py report <产品ID> [天数]` |
| 示例 | `python3 scripts/price_archiver.py report DJI_Pocket3 30` |

---

## 数据保留策略

- **保留周期**: 30天
- **清理方式**: 每周一清理（由日报任务触发）
- **预计空间**: 5产品 × 30天 × ~1KB ≈ 150KB/年
