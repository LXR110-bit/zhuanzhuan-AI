# 历史分析模块使用示例

## 快速开始

### 1. 价格对比（7天/30天）

```bash
cd ./运动相机追踪/scripts
python3 price_history_analyzer.py compare DJI_Pocket3
```

**输出示例：**
```json
{
  "product_id": "DJI_Pocket3",
  "price_type": "aihuishou",
  "current": {"price": 1650, "date": "2026-04-26"},
  "7day_ago": {"price": 1740, "date": "2026-04-19"},
  "30day_ago": {"price": 1890, "date": "2026-03-27"},
  "7day_change_pct": -5.17,
  "30day_change_pct": -12.70
}
```

### 2. 趋势分析

```bash
python3 price_history_analyzer.py trend DJI_Pocket3
```

**输出示例：**
```json

  "consecutive_days": 5,
```

### 3. 偏离度分析

```bash
python3 price_history_analyzer.py deviation DJI_Pocket3
```

---

## 异动级别说明

| 级别 | 条件 | 推送策略 |
|------|------|----------|
| 🔴 S级 | 单点异常≥2种 **且** 趋势异常≥1种 | 立即推送 |
| 🟠 A级 | 单点异常≥1种 **且** 趋势异常≥2种 | 24h内推送 |
| 🟡 B级 | 单点异常≥1种 | 加入监控 |
| 🟢 C级 | 趋势异常≥1种 | 日报汇总 |
| ⚪ N级 | 无异常 | 无 |

```python
from price_history_analyzer import *

# 单产品分析
result = analyze_product_full("DJI_Pocket3")
```
