## 一、价格爬取标准化流程

### 1.1 成色等级标准化

| 等级代码 | 名称 | 定义 | 适用平台 |
|---------|------|------|---------|
| `NEW` | 全新未拆封 | 包装未拆，配件齐全，有发票 | 爱回收/闲鱼 |
| `99` | 99新 | 外观完美无痕，屏幕无划痕，无拆修，功能正常 | 爱回收/闲鱼 |
| `95` | 95新 | 轻微使用痕迹，屏幕微小划痕，无拆修 | 爱回收/闲鱼 |
| `90` | 9成新 | 明显使用痕迹，有磕碰，功能正常 | 爱回收/闲鱼 |

### 1.2 爱回收估价流程映射

**标准爬取选项**：

```
步骤1: 版本选择
  - 大陆国行（默认）
  - 官换机

步骤2: 套装类型
  - 单机版
  - 标配
  - 全能套装
  - 其他套装（Vlog/长续航等）

步骤3: 外观成色 → 映射到等级
  - 外观完好无痕迹 → 99新
  - 轻微磨损掉漆 → 95新
  - 明显磨损磕碰 → 90新

步骤4: 屏幕外观
  - 屏幕完美无划痕 → 99新
  - 轻微划痕 → 95新
  - 磕碰或破裂 → 90新/不收

步骤5: 功能检测
  - 显示正常
  - 显示异常（不收）

步骤6: 拆修史
  - 无拆修
  - 有拆修（价格降低）
```

### 1.3 闲鱼官方回收估价流程映射

**标准爬取选项**：

```
步骤1: 正常进入桌面 / 全新机
  - 全新机 → NEW（全新未拆封）
  - 正常进入桌面 → 继续评估

步骤2-7: 同爱回收流程
```


```
└──────┬──────┴──────┬──────┴──────┬──────┴────────┬────────┘
       │             │             │               │
       ▼             ▼             ▼               ▼
┌─────────────────────────────────────────────────────────────┐
│                      数据处理层                              │
```

### 4.2 云电脑扫描流程

```
日程触发(每2小时)
    │
    ▼
读取 categories.json
    │
    ▼
并行 search_web 搜索价格
    │
    ▼
计算置信度 + 异动检测
    │
    ▼
更新 price_cache.json (市场价部分)
    │
    ▼
归档到 trend_history/
    │
    ▼
如有异动 → 推送企业微信
```

### 4.3 云手机爬取流程

```
触发条件:
  - 日程触发(每日)
  - S级信号触发
  - Dashboard手动触发
    │
    ▼
读取待爬取队列
    │
    ▼
对每个机型:
  ├─ 选择成色选项(NEW/99/95/90)
  ├─ 执行估价流程
  ├─ 截图保存
  └─ 记录结果到 crawl_logs/
    │
    ▼
更新 price_cache.json (对应成色等级)
    │
    ▼
对比历史价格，检测异动
    │
    ▼
如有异动 → 推送企业微信
```

### 4.4 配置修改流程

```
Dashboard编辑配置
    │
    ▼
验证输入(机型ID唯一性等)
    │
    ▼
写入 categories.json
    │
    ▼
立即生效:
  - 下次扫描包含新机型
  - 下次日报展示新机型
  - 无需重启任何服务
```
