### daily_price_records/2026-05-02.json实际数据
```json

    "platforms": {
      "xianyu_market": {"price": null, "previous_price": 1568.0, "change_1d": null},
```

### 根因分析
- daily_price_records中xianyu_market.price=null，但previous_price有值

- 异动判断只能依赖粗略估算，S/A级判定不可靠
- 仅dji_pocket3因xy_official有数据才能算出-20.31%

### 建议修复
1. 检查price_daily_recorder.py：确保采价结果正确写入daily_records
2. 采价后强制刷新change_1d计算
3. 在12:00/17:30异动检测前，先用前一日records补算change_1d

## Issue #7: DDR5 16G价格信号矛盾 [P3]

### 发现时段
07:30 早盘异动检测

### 实际日志数据
```
07:30早盘: DDR5 16G 闲鱼920-1057元, 历史基线680-780元, +35.5% S级
12:00午间: DDR5 16G 680-780元, change=0% B级
21:00全量: DDR5 16G 闲鱼市场价=350元(search_web)
```

### price_cache.json最终值
```json
"ddr5_16g": {
  "xianyu_market": {"price": 350},
  "change_1d": null,
  "change_1d_by_platform": {"xianyu_market": null, "aihuishou": null, "xianyu_official": null}
}
```

### 矛盾分析
- 07:30 mobile_use采集920-1057元（+35.5%）
- 12:00 读cache显示680-780元（0%）
- 21:00 search_web采集350元
- 三次数据差异巨大，可能原因：
  1. 不同搜索词返回不同型号（DDR5 4800 vs 5600 vs 6000）
  2. 单条/套条混淆
  3. search_web搜索精度不足

### 建议修复
1. DDR5细分为具体型号（DDR5-4800 16G单条 / DDR5-5600 16G套条等）
2. 搜索关键词明确频率和规格
3. 排除套条价格
