## 🎯 异动分级说明

| 级别 | 触发条件 | 含义 | 推送策略 |
|------|----------|------|----------|
| 🔴 S级 | 单点异常≥2种 **且** 趋势异常≥1种 | 强烈异动，需立即关注 | 立即推送 |
| 🟠 A级 | 单点异常≥1种 **且** 趋势异常≥2种 | 趋势异动，可能持续 | 24h内推送 |
| 🟡 B级 | 单点异常≥1种 | 偶发异常，待观察 | 加入监控 |
| 🟢 C级 | 趋势异常≥1种 | 趋势变化，关注但不急 | 日报汇总 |

## 📝 注意事项

1. **数据依赖**：历史分析能力依赖归档数据，需要日程正常运行一段时间
2. **价格类型**：默认分析 `aihuishou.tansuo_price`（爱回收探索加价格）
3. **配置调整**：阈值参数可在脚本顶部修改（ARCHIVE_DAYS、DEVIATION_WARNING 等）
4. **扩展产品**：新产品会自动纳入扫描（基于 trend_history 目录）
