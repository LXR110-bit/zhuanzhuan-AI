### 1. 任务描述修改

**当前描述（简化版）：**

**建议修改为：**
```
执行云电脑价格扫描（含历史分析增强）

执行步骤：
1. 扫描各产品当前价格 → 更新 price_cache.json
2. 【新增】历史价格分析：
   - 对比7天/30天价格，计算涨跌幅

3. 归档当日价格快照
4. 生成日报（含历史趋势分析、异动提醒、操作建议）

调用命令：
- 分析：python3 ./运动相机追踪/scripts/price_history_analyzer.py scan-all
- 归档：python3 ./运动相机追踪/scripts/price_archiver.py archive
- 报告：python3 ./运动相机追踪/scripts/price_history_analyzer.py report {product_id}

输出文件：
- 历史分析结果：./运动相机追踪/data/history_analysis_latest.json
- 归档快照：./运动相机追踪/data/trend_history/{产品ID}/{日期}.json
```

## 📝 日程描述修改模板

可直接复制到扣子日程的「任务描述」中：

```
执行云电脑价格扫描（含历史分析增强）

【执行流程】
1. 价格扫描 → 更新 price_cache.json
2. 【历史分析】
   - 7天/30天价格对比
   - 涨跌幅计算
   - 趋势分析（连续涨跌、加速/减速信号）
   - 偏离度计算（当前价 vs 历史均值）
   - 异动检测（单点+趋势双重判断，S/A/B/C分级）
3. 价格归档 → trend_history/{产品ID}/{日期}.json
4. 生成增强日报（含异动提醒）

【调用命令】
python3 ./运动相机追踪/scripts/price_history_analyzer.py scan-all

【输出文件】
./运动相机追踪/data/history_analysis_latest.json

【异动级别说明】
🔴 S级：单点异常≥2种 + 趋势异常≥1种 → 立即推送
🟠 A级：单点异常≥1种 + 趋势异常≥2种 → 24h内推送
🟡 B级：单点异常≥1种 → 加入监控
🟢 C级：趋势异常≥1种 → 日报汇总
```
